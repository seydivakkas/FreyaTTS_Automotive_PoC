# F0–F6 Pipeline Trace (20261126T001600Z)

1. **Ingress (`backend/main.py:voice`, `backend/audiosocket_server.py:AudioSocketOrchestrator`)**: Web accepts `pcm_s16le` mono at 8/16/24/44.1/48 kHz via `/ws/voice` with single-use ticket; AudioSocket accepts 3-byte `!BH` packets at 8 kHz 160 samples (320 bytes / 20 ms), handling `AUDIOSOCKET_DTMF (0x03)` raw and `AUDIOSOCKET_AUDIO (0x10)`.
2. **F0 Input (`backend/car_denoiser.py`, `backend/audio.py`, `backend/dtmf.py`)**: Raw Goertzel DTMF tap runs before enhancement (`session.goertzel_detector`), followed by `InboundCarDenoiser` (120 Hz 4th-order Butterworth HPF + spectral noise suppression + soft AGC/noise gate) and `resample()` to 16 kHz float32.
3. **F1 VAD & Endpointing (`backend/models.py:new_vad`, `backend/audio.py:Endpoint`, `backend/semantic_turn_detector.py`)**: Per-session `deepcopy` Silero CPU detector processes 512-sample (32 ms) blocks at 16 kHz; `LookbackBuffer` (300 ms) and `TwoStageBargeInController` manage interruption; `Endpoint.feed` emits finalized utterance arrays.
4. **F2 ASR (`backend/models.py:transcribe`, `backend/automotive_terminology.py`, `backend/turkish_plate.py`)**: Faster-Whisper `large-v3-turbo` CUDA/float16 (`beam_size=1`, `language='tr'`, catalog+custom hotwords) emits transcript; `canonicalize_asr_text` & `TurkishPlateParser` extract automotive entities.
5. **F3 Dialogue & Supervisor (`backend/dialogue.py`, `backend/supervisor/`, `backend/routers/crm.py`)**: `Dialogue.answer` routes rule-first + Ollama `qwen2.5:7b` extraction + automotive dispatchers; `WebSupervisor` (`off`/`shadow`/`guarded`) uses `SupervisorOrchestrator` & `ToolGateway` (`BEGIN IMMEDIATE` + `SupervisorWriteReceipt`).
6. **F4 Linguistic Frontend (`backend/text.py`, `backend/normalizer_rules.py`, `backend/automotive_frontend.py`, `backend/morphology/`)**: `normalize()` + `prepare_tts_clause()` + `clauses()` expand Turkish numbers/plates/currency/automotive terms and enforce the 92-char `config/freya_vocab.json` vocabulary.
7. **F5 Synthesis (`backend/models.py:synth`, `backend/batched_ode.py`)**: `FreyaTTS._synth_one(..., steps=32, seed=LEYLA_SEED=9)` or `BatchedODEEngine` produces 48 kHz float32 audio with `check_voicedness` (<0.06 collapse fallback) and `OrderedDict` LRU greeting cache (`SYNTH_CACHE_MAX=32`).
8. **F6 Rendering & Transport (`backend/dsp.py`, `backend/audio.py`, `backend/session.py`)**: `apply_fade_and_comfort_noise` (10 ms cosine fade) + `apply_telephony_eq_and_downsample_8k` (120 Hz HPF + 3.2 kHz boost + polyphase 48k→8k + soft tanh limiter + PCM16) or web 16 kHz PCM16, paced in 20 ms frames via `pace()` with `turn != self.generation` fence.
