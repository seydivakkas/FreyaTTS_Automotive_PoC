# M11 → Fiziksel kabul devam görevi (M12 değildir; yeni özellik modülü açılmıyor)

Kod tabanını `FreyaTTS_M11_Physical_Acceptance_v1.zip` içinden kullan. Yeni model eğitimi, yeni mimari veya gerçek telefon kampanyası başlatma. Önce `scripts/check_m11.ps1` üzerinde Windows 11/Python 3.11/RTX 4070 uyumunu doğrula. M11 JSON raporunda HOLD olan her kapıyı **tek tek gerçek delil** sunularak geç; SHA-256, model commit, seed=9, çağrı/klip kimliği ve insan gözlem bilgisi kaybolmamalı. 320 golden seti değiştirme. İlk 12 cümle smoke, sonra 320 A/B ve dinleme değerlendirmesi. A01-YT referanslarında insan onayı olmadan telaffuz terfisi yapma. Gerçek PBX'de `REPORT_QUEUE_DRAINED` + `FLUSH_MEDIA` + `QUEUE_DRAINED` ve bağımsız akustik ölçümü birlikte doğrula. Etiketli STT/VAD ve gerçek codec oynatması başarısızsa production pilotunu açma. Testi geçmeyen veya ölçülmeyen bir kapıya PASS yazma.
